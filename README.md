# Gerenciador Casa

App de gestão da casa: tarefas das funcionárias, mensagens por WhatsApp, despesas e recibos. PWA, mobile-first, em português.

As regras, o mapa do projeto e onde cada coisa roda estão em [`CLAUDE.md`](CLAUDE.md) e [`AGENTS.md`](AGENTS.md). Pendências em [`roadmap.md`](roadmap.md).

```sh
npm i
cp .env.example .env.local   # chaves publicáveis do Supabase
npm run dev
npm test
```
